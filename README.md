# My Profile ReadMe
I will be deleting my GitHub account in the next few weeks, [since one should not have to rely on a proprietary platform to share free software repositories](https://www.gnu.org/philosophy/whats-wrong-with-github.html). All my repositories are on Codeberg (minus `jacob-willden.github.io`, which just redirects to my portfolio site). All future contributions to GitHub-exclusive repositories from me will be done via [GitGost](https://gitgost.livrasand.com/) or another platform that allows me to contribute [without needing to run non-free JavaScript](https://www.gnu.org/philosophy/javascript-trap.html).

---

All my contributions are authored without large language models (LLMs), [without software patents](https://endsoftwarepatents.org/innovating-without-patents), [without digital restrictions management](https://www.defectivebydesign.org/drm-free), and without being privacy-invasive. And they are always released under [licenses that are free (libre) and GPL-compatible](https://www.gnu.org/licenses/license-list.en.html).

I stand with libraries, including Internet Archive, in their right to [making human knowledge available to everyone, both physically and digitally](https://www.battleforlibraries.com).
